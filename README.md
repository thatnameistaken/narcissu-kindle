# narcissu-kindle
Narcissu port for E-Ink Kindles (requires KOReader)<br>

Tested only on Kindle Basic (2024), Firmware 5.19.2, support for other devices may vary<br>

English and Japanese language support, with optional furigana<br>

AI was used in the process of making the port

## Installation
1. Download and extract latest zip from releases
2. Copy narcissu.koplugin into koreader/plugins/
3. Restart KOReader and open Tools → More tools → Narcissu.

## Controls
Tap the text to advance. Its a visual novel, what do you expect.<br>

Audio is supported, pair Bluetooth headphones or speakers and set volume inside Amazon's UI before opening KOReader as it isn't possible to do while in game

## Bugs 
Audio may be finnicky<br>

Bluetooth occasionally disconnects
